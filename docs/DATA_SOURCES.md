# Источники данных

## Котировки

`data/rounds.json` содержит подготовленный локальный snapshot дневных цен закрытия MOEX ISS, board `TQBR`: 60 наблюдений до точки решения и 30 после. Каждый сценарий хранит URL исходного ISS-запроса в `source`.

`scripts/fetch_data.py` используется только для подготовки данных. Он выбирает непустые строки TQBR и реальные торговые дни. Runtime не обращается к MOEX и не создаёт синтетические значения.

## Исторические факты

Ссылки на факты хранятся в `sources` каждого сценария. В интерфейсе явно разделяются подтверждённые сведения и гипотезы о реакции рынка.

## Ограничения

MOEX ISS может менять доступность и формат API; поэтому демонстрация работает на локальном approved snapshot. При отсутствии или повреждении snapshot сервер возвращает `DATA_UNAVAILABLE`.

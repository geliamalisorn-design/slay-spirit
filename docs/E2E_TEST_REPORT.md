## Адаптивность и визуальные проверки

| Viewport | Результат |
|---|---|
| 1920×1080 | Пройдено: полный пользовательский путь, снимки всех состояний |
| 1440×900 | Пройдено: полный пользовательский путь, снимки всех состояний |
| 1366×768 | Пройдено: полный пользовательский путь; короткий ноутбучный layout |
| 1280×720 | Пройдено: полный пользовательский путь; короткий ноутбучный layout |
| 1024×768 | Пройдено: полный пользовательский путь, колонки перестраиваются |
| 768×1024 | Пройдено: полный пользовательский путь, портретный tablet layout |
| 390×844 | Пройдено: полный пользовательский путь, мобильный layout |
| 375×667 | Пройдено: полный пользовательский путь, компактный мобильный layout |

На всех размерах проверены отсутствие горизонтального переполнения и наложений интерактивных элементов, имена кнопок, SVG с `viewBox`, поля формы от 16 px и контраст ключевых цветовых ролей от 4.5:1. Google Fonts подключены неблокирующе. E2E подменяет CSS Google Fonts пустым ответом, чтобы сетевой CDN не задерживал браузерные проверки; поэтому эта проверка подтверждает системный fallback, а не live-загрузку внешних шрифтов. Playwright повторно прошёл после исправления мобильных вкладок; неожиданных ошибок JavaScript/консоли не выявлено. Font-load observations сохраняются в `artifacts/ui-audit/font-load-status.json`.

## Запуск и артефакты

Playwright: `2` браузерных теста пройдены на восьми размерах; каждый размер завершил регистрацию, туториал, учебную практику и один обычный игровой раунд. Проверены мобильные вкладки, сохранение подсказки после перезагрузки, профиль и запись фильтров. Backend/unit/API: `19` тестов пройдены, включая HTTP-прохождение пятираундовых Easy, Medium и Hard с проверкой серверной разблокировки. Python compile check и валидатор набора данных пройдены.

88 PNG-снимков восьми разрешений сохранены в `artifacts/ui-audit/` с префиксами `wide`, `desktop`, `laptop-1366`, `laptop-1280`, `tablet-landscape`, `tablet-portrait`, `mobile` и `mobile-small`. Состояния включают главную страницу, регистрацию, вход, туториал, реальный график туториала, учебный раунд и его результат, уровни, раунд, результат и профиль.

Согласованных эталонных скриншотов в репозитории не найдено; новые снимки не назначались эталонами визуальной регрессии.

Каждый браузерный прогон создаёт тестовый аккаунт в отдельной временной базе; существующие пользовательские данные не изменяются. Production deploy не выполнялся.

## Повторный запуск

```powershell
uv run --with-requirements requirements-e2e.txt python tests/e2e/test_ui_playwright.py
uv run --cache-dir .uv-cache python -m unittest discover -s tests -v
uv run --cache-dir .uv-cache python -m compileall -q server.py tests/e2e/test_ui_playwright.py
```

`node scripts/build_frontend.mjs` — команда копирования статических файлов в `dist/`; в проверенной среде Node.js/npm отсутствуют, поэтому команда не запускалась. Изменённая таблица стилей синхронизирована в `dist/styles.css`, SHA-256 источника и копии совпадает.

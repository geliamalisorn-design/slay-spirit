# Slay Investments

Slay Investments — образовательная игра о принятии решений в условиях неопределённости. Игрок проходит пять исторических ситуаций Московской биржи, изучает контекст и нормированный график, формирует гипотезу, выбирает виртуальную стратегию и получает проверяемый разбор.

## Запуск

Требуется Python 3.10 или новее. Внешние пакеты не нужны.

```powershell
python server.py
```

Откройте <http://localhost:8000>.

## Данные

`data/rounds.json` содержит пять воспроизводимых ситуаций с дневными ценами закрытия TQBR: 60 торговых сессий до решения и 30 после. `data/education.json` содержит утверждённые факторы, мини-тесты и образовательные выводы.

Во время игры внешние API не вызываются и котировки не генерируются. Если локальный набор отсутствует, сервер возвращает понятную ошибку `DATA_UNAVAILABLE` и не запускает игру.

Для подготовки нового snapshot:

```powershell
python scripts/fetch_data.py
```

## Архитектура

- `server.py` — HTTP backend, валидация сценариев, SQLite, state machine раунда, scoring и расчёт портфеля.
- `web/index.html`, `web/styles.css`, `web/app.js` — адаптивный интерфейс без frontend-зависимостей.
- `data/rounds.json` — проверенные котировки и исторический контекст.
- `data/education.json` — локальный approved-контент без вызова LLM во время раунда.
- `llm_provider.py` — граница preparation-time LLM и явный offline fallback.
- `scripts/fetch_data.py` — подготовка котировок MOEX ISS.

## API

- `POST /api/session` — создать сессию из пяти сценариев.
- `GET /api/session` с заголовком `X-Session-Id` — получить текущее состояние.
- `POST /api/answer` — зафиксировать прогноз, стратегию, аргументацию и ответы мини-теста. Будущие цены возвращаются только после фиксации.

Подробный контракт находится в `docs/API.md`.

## Игровые правила MVP

- Каждый раунд начинается со 100 000 ₽: 50% в акции и 50% в деньгах.
- `buy` — 100% в акции, `hold` — 50%, `sell` — 0%.
- Рост: от +5%, падение: от −5%, иначе — без существенного изменения. Порог задаётся на backend.
- Отдельно считаются историческая точность, прогноз, понимание факторов и финансовый результат.
- Комиссии, налоги и дивиденды не учитываются и явно указаны в интерфейсе.

Проект предназначен только для обучения и не является инвестиционной рекомендацией.
